# R17：10 个训练类与 20 个推理类历史 PR 盲测

## 结论

R17 达到“有提升再提交”的门槛。冻结判断为 `16 accept / 1 check / 13 reject`，
oracle 为 `14 accept / 4 check / 12 reject`。同一队列 exact 从旧路数的 `9/30`
（30.0%）提高到 `13/30`（43.3%），提升 `+13.3 pp`；冻结为非 accept 的 14 例中，
exact 从旧路数的 `2/14` 提高到 `6/14`。唯一的 check（TensorRT-LLM #18596）命中，
check precision 为 100%；13 个 reject 命中 5 个（38.5%）。

绝对二分类准确率仍只有 `14/30`。最大误差不是技术判断本身，而是 blind source 无法直接观察
oracle 所依赖的评审活跃度，以及目标硬件/生成 bindings 缺口被过度解释为 disposition reject。
R18 因此保留技术与 disposition 双输出，并把“近期、修复方向有限、候选测试存在”的可修复失败
纳入 check；对成熟推理 PR，目标环境缺失不再单独构成 reject。

## 盲测边界与执行

R17 在 metadata-only 阶段冻结 `10 training + 20 inference`，推理四项目各 5 例；候选正文、
源码、状态、review、评论、CI 和标签在 selection/test-plan 锁前均不可见。选择后获取清洗正文与
精确 base...head；四段 outcome-bearing 正文块在落盘前删除。30 个 head 均匹配选择锁，静态检查
无冲突标记或语法错误。判断锁写入后才抓取 GitHub 最终状态与人类反馈。

远端执行环境为 `2×NVIDIA A100-SXM4-40GB`。FlashInfer 数据边界、TorchTitan 固定依赖、vLLM
与 SGLang 的可选导入均采用 fail-closed 隔离；TensorRT-LLM 使用 LFS-safe 干净 worktree，无法
越过生成 bindings 的用例如实记为 capability gap，没有伪装成执行通过。

关键反例包括：verl #7685、FlashInfer #4861、SGLang #27203 与 vLLM #44544 的候选 exact
断言真实失败；Liger #1157、TorchTitan #4398/#3521、verl #6526、SGLang #37612/#27312/
#27274 与 vLLM #54990 的聚焦测试通过。FlashInfer #3497、SGLang #27291、TensorRT-LLM
#14922、vLLM #44513/#44572 虽受目标环境或测试完整性限制却最终 merged，形成 R18 的
target-gap transfer 规则。

## R18 前瞻迭代

R18 为 30 个纯推理 PR：vLLM/SGLang 各 8 个，TensorRT-LLM/FlashInfer 各 7 个；R19
轮换 8/8 份额，R20 各 5 个，最终四个 draft 各累计 25 个。未来组仍不提前选样。

1. 近期小 PR 的 title-scoped 失败若修复方向和 residual 均有限，可判 check；安全、完整性、
   广域 ownership 或成熟 PR 的 exact failure 仍 reject。
2. check 需要 outcome-free readiness proxy：已处理反馈、QA 有限跟进、精确 base/head 复现或
   evaluator 核心测试；`cannot run`、`happy to close`、draft/CI 未请求等文字为 veto。
3. 成熟推理 PR 若有候选测试路径、生产 route 明确、静态完整，且可达检查无反例，则目标架构、
   bindings 或 topology 缺失仅记 bounded-gap，不直接 reject。
4. stack/supersede 标记只控制选样多样性，不再单独决定 disposition。
5. 技术 contract 与历史 disposition 继续分别冻结，且所有策略只前瞻应用。

工作量账本：已完成 `50 communication + 50 training + 20 inference`；剩余 `80 inference`。
